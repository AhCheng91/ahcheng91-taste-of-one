# ahcheng91-taste-one

A program that paints one picture to `/output/entry.png`: a bowl of ramen seen from directly above,
drawn pixel by pixel in code — broth, noodles, a jammy egg, chashu, nori, scallions and steam — and
encoded as a PNG with nothing but Node's own zlib.
